# .github

Default community health files for every repository under [mazino2d](https://github.com/mazino2d). GitHub uses a file from here whenever a repository has no file of its own, namely:

- [SECURITY.md](SECURITY.md)
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)
- [CONTRIBUTING.md](CONTRIBUTING.md)
- [PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md)
- [Issue templates](.github/ISSUE_TEMPLATE/) (bug report, feature request)

A license is not inherited this way: each repository needs its own `LICENSE` file.
