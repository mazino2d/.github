# Contributing

Thanks for taking the time to help. This guide covers every repository under [mazino2d](https://github.com/mazino2d) that has no `CONTRIBUTING.md` of its own; a repository's own README or docs take precedence.

## Before you start

- **Bugs and ideas:** open an issue first, using the bug report or feature request template, so we can agree on the approach before you write code.
- **Security problems:** do not open an issue. Follow the [security policy](SECURITY.md).
- **Small fixes** (typos, docs, obvious bugs) can go straight to a pull request.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep the change focused: one fix or feature per pull request.
3. Use a [Conventional Commits](https://www.conventionalcommits.org/) title, for example `fix(api): handle empty input`; pull requests are squash-merged with that title.
4. Make sure the repository's checks pass, and add or update tests and docs where it makes sense.
5. Fill in the pull request template and link the related issue.

Every review thread must be resolved before a pull request can be merged.

## Conduct

By taking part you agree to follow the [code of conduct](CODE_OF_CONDUCT.md).
